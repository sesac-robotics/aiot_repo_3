# 학생 모니터링 실험 기록 (모델 선정 · 학습 방식 · 문제와 해결 · 성능 추이)

MediaPipe로 측정하고, 직접 수집한 데이터로 학습한 모델로 판단한다.
처음 보는 테스트에서 자세 균형 정확도는 규칙 0.591 → 0.872, 얼굴 정상 10분당 오경보는 48.5건 → 4.4건.

- 모든 정확도는 **균형 정확도** (상태별 재현율의 평균, 드문 상태도 같은 비중)
- 얼굴 이미지·Grad-CAM 이미지는 생체 정보라 이 문서에 넣지 않는다 (글과 수치만)

## 1. 왜 MediaPipe 위에 학습 모델인가

MediaPipe(Pose / Face Landmarker)는 사전학습 딥러닝 모델로 랜드마크·표정 점수·고개 각도·사람 윤곽을 **측정**한다.
"문제 상태인가"는 판단하지 않으므로, 그 위에 판정 모델을 따로 학습했다. 임계값 규칙만 쓰면:

| 문제 | 예 |
|---|---|
| 헷갈리는 동작을 구분 못 함 | 깜빡임 → 졸음 (오경보 70%), 물 마시기 → 하품 (79%), 말하기 → 하품 |
| 자리마다 정상 시선 방향이 다름 | 강의 공간을 보는 것도 정면 미응시로 판정 (오경보 67%) |
| 여러 값이 함께 변하는 자세 패턴 | 약한 거북목·구부정을 축별 임계값으로 놓침 |
| 새 환경에서 성능 급락 | 처음 보는 장소·옷에서 자세 0.502, 얼굴 0.540 |

## 2. 모델 선정

| 역할 | 선정 모델 | 이유 | 비교한 대안 |
|---|---|---|---|
| 자세 수치 | MLP 5 → 32 → 32 → 4 | 입력 5개, 약 9KB, 판정 0.04ms (CPU) | - |
| 얼굴 수치 (프레임) | MLP 56 → 64 → 64 → 5 | 비교 기준 | 시계열 모델로 대체 (0.830 → 0.893) |
| 얼굴 시계열 | 1D-CNN (Conv1d × 2, 커널 5) | 최근 30프레임의 짧은 모양 변화를 직접 봄 | GRU: 0.860, 잦은 깜빡임 오경보 35.8% |
| 이미지 (자세·얼굴) | MobileNetV3-Small, ImageNet 사전학습 → 미세조정 | 약 250만 파라미터, 적은 데이터로 미세조정, 4GB VRAM 학습·노트북 실시간 | 얼굴 백본 앞 9블록 고정: 0.707로 하락 |
| 수치 + 이미지 | 후기 융합 (확률 가중 평균) | 역할 분담, 학습 없이 후처리 적용 | 중간 융합(한 모델): 얼굴 오경보 39% |

- 이미지 모델은 좌우 반전 증강을 쓰지 않는다 (기울기·고개 방향 정보가 바뀜)
- 모델 선택 기준은 **오경보 최소화** (자주 틀리는 알림은 무시된다)

## 3. 학습 케이스

같은 프레임·같은 지표로 비교. 구성은 통째로 떼어 둔 검증 세션으로 고르고, 최종 판단은 처음 보는 테스트로 한 번만.

| 케이스 | 입력 | 모델 | 최종 사용 |
|---|---|---|---|
| A 규칙 (MediaPipe만) | MediaPipe 수치 | 임계값 | 비교용 (`mediapipe_only/`) |
| B 수치 학습 | 자세 변화량 5개 / 얼굴 수치 56개 | MLP | 자세 |
| C 이미지 학습 | 상반신 crop / 얼굴 crop 128×128 | MobileNetV3-Small | 자세 · 얼굴 |
| D 수치 + 이미지 (중간 융합) | 이미지 + 수치 | 한 모델 안에서 이미지 특징 64 + 수치 특징 32 concat | 미채택 |
| E 수치 + 이미지 (후기 융합) | B · C 확률 | (1 − w) × B + w × C | 자세 (w 0.6) |
| T 시계열 (얼굴) | 최근 30프레임 × 수치 56개 | 1D-CNN | 얼굴 |
| F 시계열 + 이미지 (후기 융합) | T · C 확률 | 0.3 × T + 0.7 × 영역 연결(C) | 얼굴 |

- D와 E는 처음부터 함께 비교했다. 얼굴 검증: D 0.801 · 오경보 39%, E 0.845 · 오경보 5%
- E는 따로 학습하므로 영역 연결·각도 보정·앙상블을 다시 학습하지 않고 넣을 수 있고, 이미지가 없는 프레임은 수치 쪽만으로 판정한다
- 자세는 같은 테스트로 D를 평가하지 않았다 (초기 같은 세션 검증에서만 D 0.994, E 0.996)
- w는 학습하지 않는다. 검증 세션에서 w를 0~1로 바꿔 곡선을 그리고 오경보가 가장 적은 값을 고른다 (`evaluation/weight_curve.py`, `face_weight_curve.py`)

**앙상블**: 같은 구조·데이터로 seed만 바꿔 여러 번 학습하고 추론 때 확률을 평균한다.
seed마다 결과가 흔들렸고 (같은 설정 검증 0.952 / 0.889), 한 모델의 확률이 과신하면 결합 비중이 스위치처럼 급변했기 때문.

| 영역 | 수치 쪽 | 이미지 쪽 | 결합 |
|---|---|---|---|
| 자세 | MLP 1개 (`models/v6/posture_mlp.pt`) | 배경 제거 3 + 실루엣 3 (`models/v6/cnn_*`) | 0.4 : 0.6 → 각도 보정 |
| 얼굴 | 시계열 3개 (`models/face/v1/seq*.pt`) | 이미지 2개 (`models/face/v2/cnn_ls_erase*.pt`) | 0.3 : 0.7 → 근거 보정 |

## 4. 문제와 해결

**공통**

| 문제 | 원인 | 해결 | 결과 |
|---|---|---|---|
| 검증 0.99인데 새 장소에서 급락 | 같은 세션 뒷부분으로 검증해 점수가 부풀려짐 | 검증은 세션 통째로, 테스트는 구성을 정한 뒤 한 번만 | 구성 결정과 최종 판단 분리 |
| seed마다 결과 차이가 큼 | 적은 데이터 · 확률 과신 | seed 앙상블 + 라벨 스무딩 | 결합 비중이 다이얼처럼 동작 |

**자세**

| 문제 | 원인 | 해결 | 결과 |
|---|---|---|---|
| 새 장소에서 이미지 모델 0.441 | 배경을 외움 (지름길) | 사람 윤곽으로 배경 제거 | 0.706 |
| 깃 셔츠에서 바른 자세 재현율 0 | 옷 모양을 외움 (Grad-CAM 확인). 색 변형 0.505 · 흑백 0.489로는 못 막음 | 옷 5종 추가 수집 + 윤곽만 남긴 실루엣 | 세션 검증 0.920 |
| 수치 모델이 바른 자세를 못 맞힘 | 기준 자세 측정 오차에 약함 | 오프셋 증강 (기울기 ±3°, 비율·높이 ±0.03) | 0.619 → 0.777 |
| 고개 기울임을 놓침 | 이미지에서 약함 (재현율 0.56) | 목 꺾임(귀 − 어깨 기울기) ≥ 10°면 고개 기울임 | 재현율 0.73 |
| 이미지 비중이 스위치처럼 동작 | 이미지 확률 과신 | 이미지 6개 앙상블 | w 0.7까지 평평 (0.970~0.975) |

**얼굴**

| 문제 | 원인 | 해결 | 결과 |
|---|---|---|---|
| 160×120 프레임에서 눈이 안 보임 | 얼굴이 너무 작음 | 수집 때 원본 해상도에서 얼굴 128×128 crop 저장 | 눈·입 모양 학습 가능 |
| 이미지 모델 과적합 | 적은 데이터 | 라벨 스무딩 0.1 + 무작위 가리기 0.5 + seed 2개 | C 0.743 → 0.842 |
| 강의 공간을 보는 것을 영역 밖으로 오판 | 이미지는 고개 방향만 알고 자리별 강의 공간 위치를 모름 | 영역 연결: 등록한 방향 안(5°)이면 영역 밖 → 앞 보기 | 앞 보기 오경보 22% → 5% |
| 깜빡임·말하기를 졸음·하품으로 오판 | 프레임 한 장으로는 구분 불가 | 30프레임 시계열 모델(1D-CNN) × 3 | 0.845 → 0.885, 오경보 5% → 2.8% |
| 새 장소에서 성능 하락 | 학습 장소가 적음 | 새 장소 데이터로 이미지 모델 재학습(v2) + 눈 감김·입 벌림 근거 보정 | 처음 보는 장소 0.787 |

영역 연결 허용 범위는 0°·2°·5°를 비교했다. 0°는 영역 밖 재현율 +0.03 대신 강의 공간 오경보가 6.7% → 17.9%로 늘어 5°를 유지했다.

## 5. 성능 추이

**자세**

| 단계 | 평가 데이터 | 결과 | 알게 된 것 |
|---|---|---|---|
| 초기 (10-13) | 같은 세션 뒷부분 | A 0.641 · B 0.971 · C 0.989 · D 0.994 · E 0.996 | 검증이 학습과 거의 같아 부풀려짐 |
| 새 장소 첫 테스트 | 새 장소 · 흰 티 | A 0.663 · B 0.652 · C 원본 0.441 → 배경 제거 0.706 · E 0.752 | 이미지가 배경을 외움 |
| 깃 셔츠 | 새 장소 · 깃 셔츠 | 배경 제거 0.415 · 색 변형 0.505 · 흑백 0.489 | 옷 모양을 외움 |
| 옷 5종 + 오프셋 증강 | 10-14 / 새 환경 | B 0.777 / 0.777 · E 0.786 / 0.776 | 데이터 다양성 · 기준 오차 대응 |
| 각도 보정 추가 | 10-14 / 새 환경 | 0.813 / 0.807 | 고개 기울임 보완 |
| 세션 통째 검증 | 검증 세션 | 배경 제거 0.684 → + 억제 0.881 · 실루엣 0.920 | 실루엣이 옷 모양까지 지움 |
| 이미지 앙상블 2 / 4 / 6개 | 테스트 평균 | 0.785 / 0.792 / 0.807 | seed 앙상블 효과 |
| **최종 테스트 (구성 고정, 1회)** | 새 장소 · 모크넥 | A 0.502 · B 0.832 · C 0.854 · E 0.887 · **최종 0.885** | 고개 기울임만 약함 (0.73) |
| **테스트 4세션 평균** | 10-14 · 새 환경 · 새 장소 2곳 | 규칙 0.591 → **0.872** | 4세션 모두 0.80 이상 |

**얼굴** (검증 세션, 단계별 상세는 [results/face_history.md](../results/face_history.md))

| 단계 | 균형 정확도 | 앞 보기 오경보 |
|---|---|---|
| A 규칙 (MediaPipe만) | 0.526 | 32% |
| E 첫 결합 | 0.825 | 15% |
| 이미지 보완 (스무딩·가리기, seed 2개) | 0.871 | 22% |
| 영역 연결 + 이미지 비중 0.7 | 0.845 | 5% |
| 시계열 1D-CNN 추가 | 0.878 | 3% |
| **시계열 × 3 (최종)** | **0.885** | **2.8%** |

이미지 보완 단계는 정확도가 가장 높았지만 오경보가 22%로 늘어, 오경보가 낮은 구성을 골랐다.

| 처음 보는 장소 테스트 | 규칙 | 학습 모델 |
|---|---|---|
| 새 장소 1 (10-20, 재학습 전) | 0.481 | 0.796 |
| 새 장소 2 (10-21, 현재 모델, 실시간 재생) | 0.540 | 0.787 |
| 정상 10분당 오경보 | 48.5건 | 4.4건 |

## 6. 한계와 과제

| 한계 | 내용 | 과제 |
|---|---|---|
| 한 사람 · 연기한 데이터 | 다른 사람·실제 졸음에서 미확인, 새 장소 하품 재현율 0.67 | 여러 사람·실제 수업 데이터, 학습에 없는 사람으로 테스트 |
| 정면 카메라 1대 | 앞뒤(깊이)는 근사치, 뒤로 기댄 자세·허리가 의자에서 빠진 자세 판정 없음 | 측면 또는 뎁스 카메라 |
| 눈이 작은 사람 | 눈을 떠도 눈 감김 점수가 높아 졸음 오판 가능 | 눈 감김도 등록 때 평소 값 대비로 판정 |
| 약한 판정 | 고개 기울임 재현율 0.73, 눈만 돌린 영역 밖, 45° 넘는 옆 강의 화면 미지원 | 고개 기울임 보완 |
| 휴대폰 사용 | 필기(아래 보기)와 얼굴만으로 구분 어려움 | 범위 검토 |
| 자세 융합 방식 비교 | 같은 테스트로 중간 융합(D) 미평가 | 테스트 4세션으로 D 평가 |
| 실시간 성능 | 학생 PC GPU 약 17~18fps는 얼굴 규칙 기준 측정 | 얼굴 학습 모델 포함 구성으로 재측정 |
